# 调度语义（状态机 / 动态扩容 / 优先级保护 / 退让 / 变慢检测）

## 作业状态机

```
QUEUED → STARTING → RUNNING ──► SUCCEEDED（exit 0 + completed 事件）
                       │
                       ├──► PAUSING → PAUSED（协作暂停，断点已保存，可恢复）
                       │
                       └──► BACKOFF（统一外部不足 exit 75，到期探测）
QUEUED/RUNNING ──► CANCELLED（显式取消）
exit 0 但无完成记录 ──► RECOVERING ──►（无法确认进程/提交）RECOVERY_BLOCKED
其他非 0 ──► FAILED
```

- STARTING、RUNNING、PAUSING、尚未确认退出的状态都算**存活**。同作业同一时刻最多一次存活 attempt。
- 每次状态变更带原因/执行身份/事件序号/时间，数据库事务提交。暂停、外部不足与业务失败分别记录；调度器主动暂停不计为任务错误。
- 显式取消是业务/用户控制动作，先结束进程树并确认业务结果边界，不影响其他生产者。

## 动态运行目标与平缓扩容

- 每个任务保存**当前运行目标**（动态，可升降）、存活 attempt 数、执行模式、近期进展、统一不足、最近扩容结果、恢复时间。
- 运行目标可为 0（暂不新增/退让）；恢复探测另允许最小探索机会，不设永久最小存活数。
- 冷启动从 1 个开始（探索步长，不是上限）；多个新任务用全局启动间隔错开防突发。
- 增长条件：完成启动观察 + 有真实业务进展 + 无持续不足 + 资源可解释 + 已达到当前目标。一次只 +1。
- 同任务已有进程完成时，健康即可在当前目标内及时补位，不必每个补位都等完整学习周期。
- 一次扩容后出现不足/退化，先撤销近期增加、降低目标；一次控制动作后等确认与有效反馈，不在同一轮因重复事件连续减半。

## 高优先级保护与跨任务累计退让

- 准入按优先级降序，同级任务轮转，任务内先进先出。高优已运行且无准入需求时，低优可用健康余量。
- 高优 A 报统一外部不足 → 立即停止比 A 低优先级的新增，并开始低优先级退让；失败的 A 自行保存进度并冷却，可正常推进的 A 尽量保留。
- 退让候选：优先级低者优先，再综合最近扩容/暂停成本/是否自身报不足排序。
- 每次退让一小步，确认退出后观察 A；无改善保留已退让者继续扩大，可逐步暂停全部低优执行进程。
- 整轮保护有**截止时间**；截止后未获成功证据也解除临时冻结或进入明确新轮，不悄悄无限续期。
- A 恢复后低优从被减目标逐步放回（每次少量 + 观察 A）；A 再次受阻则撤销近期恢复并延长恢复等待。
- 失败保护轮间设置递增等待，避免不断暂停/恢复全部任务。

## 无报错变慢检测

- 按任务 + 业务阶段 + 进度语义建立近期健康基线：归一化处理速率、单元处理耗时、在途单元时长。
- 新任务/阶段切换先建样本，不把缺少基线解释为变慢；正常等待/工作量变化排除在外。
- 有在途工作且速率持续下降、耗时/在途持续上升（连续证据）→ 触发较温和的低优退让。
- 慢信号置信度低于明确不足，扩散退让更谨慎；一旦出现明确不足则转入快速保护。

## 不足重试与恢复

- 统一不足（exit 75）→ BACKOFF，指数增长 + 随机抖动的等待；恢复后逐步减少等待。
- 不因固定重试次数/累计时长自动永久放弃；长期不足进入延长等待，仍持久化、告警、保留探测机会。显式取消或业务明确终结后才不再恢复。
- 同任务单进程冷却不阻塞主循环；持久化恢复时间用 UTC，时钟跳变保守核实并保证保护状态可解除。

## 重启接管与进程身份

- 只允许一个执行调度实例（单实例 flock）。启动先恢复执行库与进程身份，再启新进程，不重启就全量拉起。
- 执行身份 = PID + 进程启动时间 + attempt_id + 令牌 + cgroup/进程树归属；PID 复用不误暂停。
- 启动先持久化 attempt 意图（STARTING），再经 launcher 握手记录真实进程；worker 在许可确认前不产生业务副作用。
- 重启后存活的旧 worker 先协作 TERM（落检查点后退出），宽限超时才强杀；随后按检查点重放——新 attempt 启动前，调度器把该作业最近一次已提交检查点复制进新 run_dir，`resume_data()` 真正恢复断点。旧 attempt 迟到事件不作用于新 attempt。
- 仅重启调度器默认保持生产者运行；显式整套服务关闭走外部生命周期管理。
