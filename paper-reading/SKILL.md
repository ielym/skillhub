# 论文阅读（paper-reading）

以**单篇内容**为解析单位的论文 / 技术资料阅读工具，面向 AI 自动执行。

## 职责与边界

- 解析对象：单篇论文，或单条非论文来源（博客、Release notes、仓库、榜单、政策、论坛帖等）。
- 交付物：一篇结构完整的正式文档，兼容 Markdown 渲染与飞书导入，而非阅读计划、简略摘要或零散问答。
- 不做：多篇横向对比 / 综合矩阵；代码复现与实验；工具链落地；文件保存路径与目录结构规划。

## 执行方式（二选一，默认「直接解析」）

### 方式 A：agent 直接解析（默认）

agent 读取输入后，直接按 `references/` 下的目标规则完成解析并产出最终文档。**不需要 API Key，不需要任何外部 harness。** 绝大多数请求都应走此方式。

### 方式 B：自定义 harness（可选，需显式触发）

仅当满足以下**任一**条件时，才切换到 harness 链路：

1. 用户显式提供 API Key，并要求用 harness 解析；
2. 用户显式要求使用自定义 harness。

harness 的现状与定位见 [harness 示例](references/harness.md)。**未满足上述条件时，不得主动引入 harness。**

## 路由

根据用户意图与输入类型，选择唯一一条子规则执行，不同功能不混杂：

| 用户意图 | 输入判断 | 子规则 |
|---|---|---|
| 精读、解读、总结、评审论文；解释模型 / 算法 / 公式 / 实验、创新性、局限、复现难度 | 论文 PDF / 正文 / 链接 / 标题，或作者 + 标题 | [论文精读](references/deep-read.md) |
| 快速了解这篇论文：研究了什么、为什么做、怎么做、贡献与结果 | 论文，只需简明客观概述 | [论文简要解析](references/skim.md) |
| 整理博客、Release、仓库、榜单、政策、论坛帖等非论文资料 | 非论文 URL 或文本 | [非论文来源整理](references/non-paper-source.md) |

无法明确判断意图时，默认按「论文精读」进入，在确认输入类型后如有偏离再切换。

## 统一输出约束

- 全程以 AI 自动执行为目标，指令均为可执行步骤，不含人工时间盒、个人知识管理工具或本地目录约定。
- 最终交付物必须同时可被 Markdown 渲染与飞书导入。公式、表格、图表的兼容细则见各子规则（论文相关的公式 / Mermaid 约束见 [deep-read](references/deep-read.md)）。
- 客观陈述为主：只依据给定材料，重要论断标注来源位置，缺失标「论文未说明」（非论文标「来源未说明」），不虚构、不猜测。
- 不替用户做「值不值得读 / 该不该用」的取舍判断；相关性与价值的判断留给用户。
- 只输出结构化内容本身；存储位置、命名与归档方式由调用方决定，本 skill 不定义。
