# 论文阅读（paper-reading）

通用论文与信息技术资料阅读工具，面向 AI 自动执行，以**单篇内容**为解析单位。

## 职责与边界

- 解析对象：单篇论文，或单条非论文来源（博客、Release notes、仓库、榜单、政策、论坛帖等）。
- 交付物：一篇结构完整的正式文档，兼容 Markdown 渲染与飞书导入，而非阅读计划、简略摘要或零散问答。
- 不做：多篇横向对比 / 综合矩阵；代码复现与实验；工具链落地；文件保存路径与目录结构规划。

## 路由

根据用户意图与输入类型，选择唯一一条子细则执行，不同功能不混杂：

| 用户意图 | 输入判断 | 子细则 |
|---|---|---|
| 精读、解读、总结、评审论文；解释模型 / 算法 / 公式 / 实验、创新性、局限、复现难度 | 论文 PDF / 正文 / 链接 / 标题，或作者 + 标题 | [论文精读](references/deep-read.md) |
| 快速判断"这篇值不值得读、和我有没有关系"，产出一张带决策的卡 | 论文，但只需定性判断与决策 | [论文泛读](references/skim.md) |
| 整理博客、Release、仓库、榜单、政策、论坛帖等非论文资料 | 非论文 URL 或文本 | [非论文来源解析](references/non-paper-source.md) |

无法明确判断意图时，默认按「论文精读」进入，在确认输入类型后如有偏离再切换到对应子细则。

## 统一输出约束

- 全程以 AI 自动执行为目标，指令均为可执行步骤，不含人工时间盒、个人知识管理工具或本地目录约定。
- 最终交付物必须同时可被 Markdown 渲染与飞书导入。公式、表格、图表的兼容细则见各子细则（论文相关的公式 / Mermaid 约束见 [deep-read](references/deep-read.md)）。
- 只输出结构化内容本身；存储位置、命名与归档方式由调用方决定，本 skill 不定义。
