# 非论文来源整理

对**单条非论文来源**（博客、Release notes、代码仓库、榜单 / 评测、政策 / 标准、论坛帖、播客 / Newsletter 等）产出简明、客观的概述。**不做评分、不推荐、不写「行动项」清单**；是否采用由用户自行判断。

## 目标

讲清这条信息"是什么、说了什么、为什么值得关注"。

## 输出结构

按以下结构输出：

1. **这是什么**：来源类型 + 一句话概括它讲了什么。
2. **主要内容**：客观列出核心信息 / 要点，逐条；区分客观事实与发布方的宣传性表述，宣传性表述标注其利益立场。
3. **为什么值得关注**：对谁、为什么有价值，客观说明。

## 纪律

- 只依据给定材料，缺失标「来源未说明」，不得猜测。
- 事实与发布方宣称分离：宣称（如"加速 2.3 倍""可用于生产"）标注为发布方主张与立场，不当作已独立验证的事实。
- 不写「升级 / 试用 / 回看 / 忽略」等行动建议，不打分。
- 记录发布日期，敏感信息提示时效衰减，但不给出具体行动时间建议。

## 输出格式

最终为 Markdown 文档，兼容飞书导入。非论文来源通常不含公式与 Mermaid；若确需图表，参考 [deep-read](deep-read.md) 的兼容规则。
