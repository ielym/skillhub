# 论文泛读

对**单篇论文**做快速定性判断，目标是一张卡 + 一个明确决策，而非完整笔记。当用户只想判断「这篇值不值得读、和我有没有关系」时使用；一旦确定要深入，转入 [deep-read](deep-read.md)。

## 产出与目标

- 一张泛读卡，以**一个决策**结尾：精读 / 存档 / 弃 / 引用。没有决策的卡视同未读。
- 能说清「这篇在讲什么、和我有没有关系、要不要再读」。
- 相关度判断需以用户明确给出或可从上下文推断的方向为基准；无法确定方向时，先询问一次再评分。

## 步骤（按顺序）

1. 标题 + 摘要 + 作者机构 + 代码是否公开的「存在性检查」→ 元信息 + 可信度初判。
2. 只读各级小标题，搭结构骨架，不读正文。
3. 只看 3 张图 / 表：框架图、主结果表、消融表 → 关键数字。
4. 读结论 + limitations → 作者自评。
5. 扫参考文献，勾出已有工作以判断其在谱系中的位置。
6. 填写泛读卡并给出决策。

## Kill Criteria（满足任一即可判「弃」，但记录理由）

1. 与目标方向无交集，且短期用不上 → 弃，仅留一行元信息。
2. 主结果表没有与 SOTA / 最强基线对比，或只跟自家上一代比 → 可信度降一级。
3. 方法依赖不可得的数据或算力，且无开源替代 → 标「不可复现」，除非有可迁移思想。
4. 已被更新工作完全覆盖 → 弃，改读后续那篇。
5. 摘要、正文、表格三处数字对不上，或结论与数据明显不符 → 可信度降为 C，谨慎引用。
6. 纯增量调参、换数据集重跑、无新机制 → 除非正对当前任务，否则弃。

## 评分与决策

**相关度 Relevance（0–5，相对目标方向的判断）**

| 分 | 含义 |
|---|---|
| 5 | 直接就是当前要做的 / 立刻能用 |
| 4 | 同方向，方法或结论可直接迁移 |
| 3 | 相邻方向，有思想可借鉴 |
| 2 | 相关但短期用不上，留档 |
| 1 | 弱相关，仅背景知识 |
| 0 | 无关（通常不建卡） |

**可信度 Credibility（A–D）**

| 级 | 判据 |
|---|---|
| A | 顶会已接收或有权威背书；实验充分 + 开源 + 结论保守 |
| B | preprint 但实验扎实、机构可信；或已接收但实验规模有限 |
| C | 基线偏弱 / 无误差棒 / 单一小规模验证 / overclaim / 无法复现 |
| D | 数字存疑、结论与数据不符、明显营销性表述 |

**决策矩阵**

| 相关度 | 可信度 | 决策 |
|---|---|---|
| 4–5 | A/B | 立即精读，进队列首位 |
| 4–5 | C | 精读但带怀疑（重点核对实验），或看代码验证 |
| 3 | A/B | 进精读队列（普通优先级） |
| 3 | C | 存档 + 打标签，等他人复现再说 |
| ≤2 | 任意 | 存档（只留元信息 + 一句话）或弃 |

## 产出纪律

- 不抄图表，只提取「一条可行动的数字」。
- 必须写一条「反常识 / 值得记住的一点」；写不出说明本文无增量信息，考虑降级为弃。

## 输出格式

泛读卡为 Markdown 文档，含：元信息（标题 / 作者 / 机构 / 链接 / 日期）、相关度、可信度、一句话结论、关键数字、值得记住的一点、决策与理由。需导入飞书时遵循 [deep-read](deep-read.md) 的公式与图表兼容规则（泛读通常不含公式与 Mermaid）。
