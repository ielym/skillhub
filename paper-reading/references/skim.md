# 论文简要解析

对**单篇论文**产出简明、客观的内容概述，帮读者快速理解这篇论文在讲什么。**不做评价、不打分、不给「值不值得读 / 该不该精读」之类的决策建议**；相关性与价值由用户自行判断。

## 目标

- 只描述论文本身：研究了什么问题、为什么做、怎么做、主要贡献是什么、结果如何。
- 控制篇幅、点到为止，不堆砌实现细节，不复制图表。

## 输出结构

按以下结构输出：

1. **标题**：论文原文标题，逐字保留，不翻译、不改写。
2. **摘要**：先给论文摘要的英文原文（逐字转录），再给中文翻译。
3. **研究问题**：论文要解决什么问题 / 研究目标是什么，一句话。
4. **动机**：为什么做、要填补的空白，1–2 句。
5. **方法**：怎么做（实验设计 / 模型 / 数据），2–3 句概括。
6. **主要贡献**：相比已有工作的新东西，逐条列出。
7. **关键结果**：核心发现与关键数字，逐条列出，并标注来源（页 / 节 / 图表）。
8. **局限与适用范围**：作者承认的局限，或结论成立的前提条件；没有则标「论文未说明」。

## 纪律

- 不使用评分、等级、可信度、「建议」等评价性措辞。
- 只依据给定材料，缺失标「论文未说明」，不得猜测。
- 摘要必须逐字转录英文原文并给出中文翻译，不得概括改写。
- 重要数字自行核对其指标方向与条件，不孤立摘录最优数字。

## 输出格式

最终为 Markdown 文档，兼容飞书导入。简要解析通常不含公式与 Mermaid；若确需，参考 [deep-read](deep-read.md) 的兼容规则。
